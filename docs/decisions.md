# Decisions

Which libraries `artifacts` uses, and the patterns the code follows. The design is in [design.md](design.md); the
security invariants these decisions keep are in [threat-model.md](threat-model.md), and the IDs below refer to it.

The balance: a dependency is taken where writing the code would be maintenance without a security or protocol reason,
and refused where the exact rule is the point (host classification, path decoding, the ID format, logging).

## Patterns

| Concern       | Pattern                                                                                                                                                                                                                                                             |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Operations    | One module holds the operations (create, update, list, get, list versions, read a file, set public, delete). Each takes validated input, the token name and its dependencies, and returns a result. The REST and MCP adapters only decode, call and encode (P5).    |
| Results       | A discriminated union, `{ ok: true, ... }` or `{ ok: false, code }`, the code from a closed set. Error codes map to an HTTP status and an MCP tool error through one `Record`, so a code without a mapping does not compile.                                        |
| Closed sets   | An `as const` array, the union derived from it, and a `Set` of it for checks at run time. Per-member handling is a `Record<Union, ...>` table.                                                                                                                      |
| Configuration | `parseConfig(env)` returns a result with a closed set of codes. The checks of every variable live once and serve both the Worker and the deployment script (HOST-2, ACC-2).                                                                                         |
| Routing       | `routeOf(request, config)` classifies a request by exact host checks and returns a union; `fetch` dispatches with a `switch` exhaustive on it. A `HEAD` gets the same `Response` as `GET`. A thrown error answers 500 and logs its error class only (DATA-1).       |
| Input shapes  | A zod schema per input, defined once and used by REST validation and the MCP tool. Issues leave validation as `{ field, reason }`, the reason from a closed set; checks across entries (duplicate paths, the merged entry file) follow the schema in the operation. |
| Bounds        | Every bound names its unit (bytes, UTF-8 bytes, code points, files) and its test measures in that unit, at and one past the bound (RES-1).                                                                                                                          |
| SQL           | Every value is bound; no statement has more than 100 bound parameters, so `version_files` rows go in chunks inside the commit's `batch()` (VER-2).                                                                                                                  |
| Waits         | Every call to D1, R2 or the Access key endpoint runs under a timeout; a timeout fails the request without a partial version (RES-2).                                                                                                                                |
| Logging       | `logEvent(event, fields)` with fields from closed sets (DATA-1).                                                                                                                                                                                                    |
| Tests         | Tests name the invariant or plan-layer ID they pin (for example `// ISO-2`, `// PL-25`).                                                                                                                                                                            |
